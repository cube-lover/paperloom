快速开始

  1. 在引擎设置中保存服务地址、模型、密钥与术语表。
  2. 选择 Zotero 论文，点击加载；检查本地解析出的原文顺序。
  3. 开始翻译并确认发送。逐段查看“待核对”提示，点击译文可复制。
  4. 导出双语笔记、Markdown 或可打印 HTML。保版式 PDF 另需桥接程序。

快捷键：Ctrl / Cmd + Shift + L 打开工作台。PDF 选文弹窗和阅读器工具栏也有入口。

当前边界

  • 双语对照位于独立工作台，不是原 PDF 页面上的译文覆盖层。
  • 页码只在解析结果有明确分页时显示；不虚构 PDF 定位。
  • 文本层解析不保证多栏阅读顺序、图表提取和数学结构完整。
  • 公式保护只覆盖已识别的 LaTeX / Markdown 片段，不是公式 OCR。
  • 章节总结支持已识别的 Markdown 标题；PDF 原有大纲与跨栏段落顺序仍需核对。
  • SimpleTex、Doc2X、MinerU 云 API 尚未集成；GROBID 可经本地桥接处理。
  • 不导入 Magic 的账户、激活数据或服务凭证。

校订译文

仅修改此任务，保留最近 5 次编辑 / 重译记录；不修改原 PDF 和已导出的笔记。
