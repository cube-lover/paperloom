# 0.9.5 安装与清除缓存验收

2026-10-15。用户报告清除当前页/全部译文后，再点翻译立即出现原结果。查明旧缓存仍被复用，独立样本复现后修复。

## 行为

- 清除会将本次范围的目标译文置空，保留历史并暂停，不发送翻译请求。
- 被清除记录具有持久化translationEpoch；再次点击翻译时使用新缓存代次，不读取清除前的磁盘/在途结果。
- 仅清当前页时不删除其他页面、论文共享缓存。新代次首次成功后仍可缓存重用；再次清除会生成另一代次。
- 旧checkpoint只有clearedAt时，恢复时以该标记初始化代次。
- 正文、图表短标签及流程图重新归组均传递代次；清除后的正文不自动借用旧图注目标。
- 再次调用引擎可能计费，新生成文本也可能与旧文本相同；不保证每次译文措辞变化。
