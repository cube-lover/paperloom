# 0.9.4–0.9.5 提交前缺陷审查

日期：2026-10-15。审查基线 `486598f`，覆盖本地未提交的快捷键、菜单、框选队列、清除/恢复、图表掩膜和开发通道改动。0.9.4 为本地中间版本，最终收口版本0.9.5。

## 已复现并修复

| 问题 | 修复与回归 |
|---|---|
| 清除时磁盘失败，第二次点清除因为 target 已空而不再写盘 | 清除重试仍保存当前状态及历史，不以新增清除数量判断持久化成功 |
| 自动页任务已启动但尚未拿到图表会话时，清除可能与它并发 | 在 clear 前检查 graphicJob.busy |
| 暂停正文没有停下手动框选队列 | 独立 pauseRegionQueue 清空待执行项并取消其 control、OCR/网络、选择层 |
| 等待空闲 promise 完成后，另一个后台任务已拿到会话 | 开始区域工作前再次检查 busy；不覆盖或释放别人的 control |
| 用户主动选择 Alt+R 等旧默认会被迁移成 Ctrl+R，菜单文字不更新 | 区分显式自定义配置与旧默认；立即刷新已存在的菜单标签 |
| 开发清除命令的 itemID 不存在时回退第一篇论文 | 明确条目不匹配就报错；限定 page/all 及菜单 action；同类开发命令也去掉隐式回退 |
| 去字掩膜擦掉字旁曲线或远处小型彩色数据点 | 按完整彩色连通分量判断字形邻域，跨出邻域和远处彩点保留；移除全框小斑点扫除；缓存版本升为7 |
| 清除只是暂时不显示，再翻译从旧缓存立即恢复 | 给被清除的记录持久化独立 translationEpoch；旧磁盘与在途缓存不再命中，其他页缓存不删除；正文和图表都传递该代次 |
| 清除后的正文在恢复时又借用图表图注目标 | 已清除记录不做跨链路目标复用；流程图重新归组继承清除代次 |

新增回归见 `tests/review-094.test.cjs`、`tests/clear-cache-095.test.cjs`，以及 checkpoint/readerview 扩展。原失败日志保留在本地 `.local/094-review-before.log`、`.local/095-clear-before.log`，没有改写成通过。
