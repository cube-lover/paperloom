验证记录：`validation/INPLACE-REPORT.md`。以下是早期功能基线，不代表当前原位翻译仍使用工作台。

基准：用户截图，以及本机 Magic 2.6.3 安装包的**静态设置界面**。仅用来识别功能需求；未复用其业务实现、激活机制、凭证或后台服务。

静态设置界面并不涵盖 Magic 所有交互和服务行为，因此本表不是完整功能等价证明。

状态定义：
- **已编码 / 本地测**：独立实现，并覆盖相应纯逻辑、模拟宿主或离线 DOM 测试；尚待真实宿主验收。
- **有集成 / 待联调**：接口已实现，外部应用 / 服务尚未实际连接验证。
- **部分**：覆盖用户目标的一部分，但交互或能力与参考插件不同。
- **待开发**：目前没有对应实现。

## 额外优化

| 优化 | 实现与验证 |
|---|---|
| 学科术语一致性 | 长术语优先、大小写开关、中英文边界处理、保护标记；纯逻辑与界面测试 |
| 公式 / 数字引文 / DOI / URL / 代码保护 | 识别后保护，丢失/重复时段落失败而不是悄悄写入；纯逻辑及模拟 API 测试 |
| 上文消歧 | 附上一段原文的尾部作为上下文；原文与任务说明分离 |
| 断点续译 | 每段持久化、重启暂停、失败段单独重试；模拟宿主测试 |
| 重复请求合并 | 并发相同段落共用请求；原文、引擎、目标语言、领域、术语与上下文进入缓存键 |
| 密钥隔离 | 登录管理器按服务地址分别存储；历史任务查对应密钥；模拟测试（非真实登录管理器验收） |
| 翻译质量提示 | 数字缺失、输出偏短、未翻译、保护标记损坏；不等同于语义评测 |
| 人工校订 | 段落编辑、人工核对标记、最近5版历史，不改原 PDF；离线界面测试 |
| 参数可追溯 | 每个任务固定配置；新配置另建任务副本 |
| AI 证据追溯 | 段落编号、可用页码、原文摘录及笔记回链 |
| 成本与隐私控制 | 请求前确认、按页段缓存、限流、暂停、配置不含密钥 |
| 大论文界面 | 复用未变的段落 DOM 节点，减少进度刷新重建；离线 DOM 测试 |

## 建议的后续顺序

1. 获得用户确认后，在现有 Zotero 中安装，完成菜单、设置、PDF解析、双语笔记、选文入口验收；不启动第二个相似空文库窗口。
2. 用用户选定的服务和1篇样本文献，检查译文、成本、术语与失败恢复。
3. 单独配置并验收 PDF2zh / MinerU / GROBID；再实现 PDF 页内覆盖及同步阅读。
4. 根据用户实际拥有的服务账号，按其正式接口文档加入云解析适配器，而不是填一个看似可用的空入口。
